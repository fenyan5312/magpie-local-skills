# 四次自动提醒提示词

以下提示词用于创建四个每日心跳任务。时间统一使用 `Asia/Shanghai`；每次都必须发送结果，不允许因“没有变化”而静默。创建自动化时使用调度工具，不手工编辑原始调度指令。

## 08:00 · 今日计划

```text
使用 $hebei-zhuanshengben-coach 执行 08:00 今日计划任务。
先动态访问河北省教育考试院普通专升本官方页面：对每个学科优先确认 2027 年考试说明/大纲；若官方未发布或附件不可用，则回退到官方 2026 年版本，并记录查询时间、公告链接、附件链接和采用年份。禁止使用第三方预测版。
读取 D:\desktop\项目\RPA\郄泽然作业特\专升本备考 的配置、最近 7 天进度和学科目录，分别为王新杰、郄泽然生成今天可执行的具体学习任务。任务按当前颗粒度拆到学科、章节、知识点，必须有预计分钟、交付物、验收标准和先后顺序。
创建或更新当天 飞轮/YYYY-MM-DD.md 和 进度/YYYY-MM-DD.json，然后发送一条带时间、两人任务清单和第一项行动的提醒。
```
