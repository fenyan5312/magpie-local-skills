# 考纲动态核验策略

## 目标

河北省教育考试院正式发布的考试说明/考试大纲/考试纲要，优先级高于任何缓存、学校讲义、公众号转载和第三方预测。每次执行任务前都要重新确认版本，不能只读取本地缓存。

## 官方入口

按以下顺序实时检查：

1. 普通专升本栏目：<https://www.hebeea.edu.cn/ptzsb/>
2. 普通专升本通知公告：<https://www.hebeea.edu.cn/ptzsb/tzgg/>
3. 官方页面中的附件链接，附件域名通常为 `file.hebeea.edu.cn`。
4. 可用站内搜索或搜索引擎补充发现，但最终证据必须回到 `hebeea.edu.cn` 官方页面或其官方附件。

已验证的 2026 年公告示例：<https://www.hebeea.edu.cn/c/2025-12-29/490705.html>。该页面标题为“关于公布2026年河北省普通高等学校专升本考试说明的公告”，包含政治、英语、高等数学等科目的官方 PDF 附件。示例只能作为回退证据，不能阻止当天重新查询 2027 年版本。

## 判定顺序

对每个学科和考试科类分别执行：

1. 查找标题和正文明确属于 **2027 年河北省普通高校/普通高等学校专升本考试说明、考试大纲或考试纲要** 的官方公告。
2. 打开公告，确认发布机构是河北省教育考试院，且目标学科存在可访问的官方附件或正文。
3. 若 2027 证据成立，标记 `year=2027`，保存页面 URL、附件 URL、发布时间、查询时间和学科清单。
4. 若 2027 不存在、只有预告/征求意见稿、附件失效或没有目标学科，立即回退查找 **2026 年**同类官方公告。
5. 若 2026 也不成立，停止该学科的考纲驱动任务生成，向用户报告缺口并请求官方材料。

“有 2027”必须同时满足：官方页面明确写明年份、属于普通专升本、包含可读取的考试说明内容。仅有考试时间、招生计划、报考问答或第三方解读，不算考纲。

## 证据记录

每次查询在 `考纲缓存/YYYY-<学科>/evidence.json` 写入：

```json
{
  "subject": "学科名称",
  "year": 2027,
  "fallback_used": false,
  "official_page": "https://www.hebeea.edu.cn/...",
  "official_attachment": "https://file.hebeea.edu.cn/...",
  "published_at": "YYYY-MM-DD",
  "checked_at": "YYYY-MM-DDTHH:mm:ss+08:00",
  "status": "confirmed",
  "notes": "官方公告标题、附件状态或缺口说明"
}
```

`status` 只能是 `confirmed`、`fallback_confirmed` 或 `unavailable`。使用 `scripts/validate_outline_evidence.py` 校验后再生成计划。

## 回写规则

- 发现 2027 官方版本时，更新所有受影响学科的计划和错题优先级，并在当天飞轮中写出“考纲切换”影响。
- 2027 缺失时使用 2026，但不能把 2026 标成 2027。
- 每次查询都要更新 `checked_at`；旧缓存只能用来比对变化，不能作为本次实时查询的证明。
